TELEGRAM-БОТ С ВСТРОЕННОЙ МИНИ-ИГРОЙ
Описание разработанного программного продукта


1. НАЗНАЧЕНИЕ И ОБОСНОВАНИЕ ВЫБОРА ПЛАТФОРМЫ

Цель работы — сделать приложение, которое работает прямо в мессенджере,
и вести учёт результатов его пользователей.

В качестве средства достижения цели я выбрал Telegram-бота, потому что это самый
короткий путь от идеи до человека: приложение не нужно скачивать — оно открывается
прямо в чате; не нужна регистрация — Telegram уже знает, кто играет; не нужен свой
клиент — платформа предоставляет готовые инструменты.

Разработанный программный продукт — Telegram-бот, который даёт пользователю доступ
к аркадной мини-игре (клон Flappy Bird) непосредственно внутри мессенджера. Бот
решает три задачи: запуск игры, сохранение результатов и ведение таблицы лидеров.


2. ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ

- /play  — открывает игру во встроенном браузере Telegram (Web App);
- /top   — таблица лидеров: место, рекорд, количество попыток;
- /help  — справка по командам;
- /start — приветствие с кнопкой запуска игры.

Бот корректно отвечает на неизвестные команды и на сообщения в групповых чатах,
где игра недоступна. Для каждого пользователя отдельно хранится личный рекорд.


3. АРХИТЕКТУРА

Система состоит из трёх компонентов:

- Telegram-бот (модуль bot.py) — принимает команды методом длительного опроса
  (long polling), отвечает через Bot API, формирует кнопку запуска игры;
- веб-сервер (модуль server.py) — отдаёт файлы игры и предоставляет программный
  интерфейс: POST /score (сохранение результата), GET /top (таблица лидеров);
- хранилище (модуль storage.py) — сохраняет результаты в файл формата JSON.

Клиентская часть — одностраничное веб-приложение на HTML5 Canvas.

Схема взаимодействия: пользователь -> команда /play -> бот отправляет кнопку ->
Telegram открывает игру -> игровой процесс -> по завершении страница отправляет
результат на сервер -> сервер сохраняет его в файл -> бот показывает статистику.


4. ИСПОЛЬЗУЕМЫЕ ТЕХНОЛОГИИ

- Python 3.14 с использованием только стандартной библиотеки (urllib,
  http.server, json, threading) — сторонние зависимости отсутствуют;
- Telegram Bot API (методы getMe, getUpdates, sendMessage);
- клиентская часть: HTML5 Canvas, JavaScript, CSS;
- формат хранения данных: JSON;
- передача данных с Telegram Web App организована по протоколу HTTPS
  через SSH-туннель.

Отказ от сторонних библиотек — осознанное решение: упрощается развёртывание
(не требуется установка пакетов) и снижается риск несовместимости версий.


5. ОСОБЕННОСТИ РЕАЛИЗАЦИИ

- Длительный опрос реализован самостоятельно поверх стандартной библиотеки,
  предусмотрено автоматическое переподключение при сбоях сети.
- Идентификация игрока выполняется по его идентификатору в Telegram, который бот
  подставляет в адрес игры. Персональная статистика ведётся без регистрации
  и авторизации.
- Запись данных выполняется атомарно (во временный файл с последующей заменой)
  и защищена блокировкой — файл не повреждается при одновременных запросах.
- Входные данные валидируются на сервере: проверяются тип и диапазон счёта,
  размер и формат запроса.
- Графическое оформление генерируется: спрайт персонажа создан по референсу,
  фон — отдельным запросом. Однотонный фон спрайта удаляется средствами Canvas
  уже в браузере, что избавляет от необходимости хранить прозрачные PNG.
- Текстура препятствий замащивается повтором (CanvasPattern), благодаря чему
  препятствия любой высоты отображаются одинаково, без растяжения.
- Предусмотрен откат на векторную графику: если изображения не загрузятся,
  игра продолжает работать, то есть оформление не влияет на работоспособность.
- Веб-сервер принимает соединения только с локальных адресов (127.0.0.1 и ::1),
  что снижает поверхность атаки.


6. ТЕСТИРОВАНИЕ

Разработано 22 автоматических теста (модуль unittest): проверка хранилища,
валидации входных данных, формирования сообщений, а также интеграционный тест,
который эмулирует Telegram Bot API на локальном сервере и проверяет полный путь
обработки команды без обращения к внешней сети. Дополнительно работа интерфейса
проверена в браузере.


7. АПРОБАЦИЯ

Проект запущен и проверен на реальных пользователях: в таблице результатов шесть
игроков, пятеро из них — реальные аккаунты Telegram, сыграно 69 попыток, лучший
результат — 54 очка.


8. ОГРАНИЧЕНИЯ

- Для работы бота необходим сетевой доступ к api.telegram.org; в отдельных сетях
  этот доступ может быть ограничен.
- Кнопка запуска игры требует HTTPS, поэтому при локальном запуске используется
  временный туннель, адрес которого изменяется при каждом запуске.
- Результаты хранятся в файле — этого достаточно для учебного проекта, однако
  при росте нагрузки потребуется переход на систему управления базами данных.
- Узнаваемый персонаж игры Dota 2 уместен в учебных целях, но при публичном
  распространении его следует заменить.


9. ПРАКТИЧЕСКАЯ ЗНАЧИМОСТЬ

Проект демонстрирует полный цикл разработки: проектирование, реализацию
клиент-серверного взаимодействия, интеграцию с внешним API, обработку
и хранение данных, автоматизированное тестирование и организацию защищённого
канала связи. Решения переносимы: на этой основе можно создавать опросы,
викторины и учебные тренажёры внутри мессенджера.
