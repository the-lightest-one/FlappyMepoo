Актуальность

  • Мессенджеры стали платформой: внутри чата работают магазины, банки, службы доставки.
  • Telegram даёт штатные инструменты для встраивания приложений прямо в чат — но в учебных проектах их возможности почти не раскрываются.
  • Задача с мини-игрой требует всего цикла разработки: клиент, сервер, хранение данных.
  • Работа проверяет на практике, какого результата можно достичь без сторонних библиотек.

Цель работы и выбор платформы

  • Цель: сделать приложение, которое работает прямо в мессенджере, и вести учёт результатов его пользователей.
  • Я выбрал Telegram-бота, потому что это самый короткий путь от идеи до человека:
    • приложение не нужно скачивать — оно открывается прямо в чате;
    • не нужна регистрация — Telegram уже знает, кто играет;
    • не нужен свой клиент — платформа даёт готовые инструменты.
  • Задачи: изучить возможности Bot API, спроектировать взаимодействие бота, клиента и сервера, реализовать хранение результатов, протестировать систему.
3 / 13

Что разработано

  • /play — присылает кнопку, открывающую игру внутри Telegram.
  • /top — таблица лидеров: место, рекорд и число попыток.
  • /start и /help — приветствие с кнопкой запуска и справка по командам.
  • Результат сохраняется автоматически: после проигрыша бот сам сообщает место и личный рекорд.
  • Регистрация и ввод данных не нужны — игрок опознаётся по идентификатору Telegram.

Надёжность и безопасность

  • Атомарная запись: результат пишется во временный файл и лишь затем заменяет основной — данные не теряются при одновременных запросах.
  • Проверка входных данных: контролируются тип и диапазон счёта, размер и формат запроса.
  • Секреты вне кода: токен бота хранится только в переменной окружения.
  • Минимум поверхности атаки: сервер принимает соединения лишь с локальных адресов.
  • Персональные данные не хранятся — только числовой идентификатор игрока.

Тестирование

  • Разработано 22 автоматических теста на встроенном модуле unittest.
  • Проверены хранилище, валидация данных и формирование сообщений бота.

  • Логика тестируется без обращения к внешней сети: тесты не зависят от интернета.
  • Интерфейс игры дополнительно проверен в браузере.

Ограничения и направления развития

Ограничения

  • Результаты хранятся в файле — при росте нагрузки нужна база данных.
  • Для кнопки требуется HTTPS: при локальном запуске адрес туннеля меняется.
  • Нужен сетевой доступ к серверам Telegram.
  • Использован узнаваемый персонаж игры Dota 2 — при публичном распространении его следует заменить.

Развитие

  • Переход на базу данных.
  • Ограничение частоты запросов.
  • Расширенная статистика по игрокам.
  • Размещение на постоянном хостинге для работы круглосуточно.
